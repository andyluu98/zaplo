🎯 Ý tưởng cốt lõi

Mỗi Agent là một “nhân viên đăng bài ảo”: phụ trách 1 hay nhiều nhóm, tự viết nội dung bằng trợ lý AI riêng và tự đăng đều theo lịch (hằng ngày / tuần / tháng + ngày cụ thể trên calendar). Bạn quản lý mọi thứ ở một nơi: prompt, API, agent phụ trách, nhóm, lịch, bài đăng.

1 Agent → N nhóm Tự viết + tự đăng Lịch định kỳ + calendar Ảnh tự đính kèm Tự duyệt / duyệt tay Nhật ký + thống kê

🧭 Orchestrator — luồng vận hành

Agent
đơn vị trung tâm: care nhóm, tự viết + đăng
Schedule Resolver
gộp luật định kỳ + mốc calendar → giờ chạy
Poster
đăng text + nhiều ảnh, chống spam, ghi log

🕒 Cơ chế lịch (chi tiết)

Định kỳ (lặp lại)

  • Hằng ngày: mỗi ngày, trong khung giờ, N bài.
  • Hằng tuần: chọn thứ (T2–CN) → chỉ đăng các thứ đó.
  • Hằng tháng: chọn ngày trong tháng (vd 1, 15) → đăng đúng ngày đó.
  • Mỗi luật có khung giờ + số bài/ngày riêng; giờ đăng random trong khung để tránh spam.

Calendar (1 lần)

  • Gắn 1 bài vào ngày–giờ cụ thể (yyyy-mm-dd HH:MM) cho dịp đặc biệt.
  • Hiện trên lịch tháng/tuần/ngày; click để xem/sửa/gỡ.
  • Kết hợp được với định kỳ trong cùng 1 agent.
⚙️ Schedule Resolver gộp tất cả luật + mốc calendar của agent, tính ra danh sách “giờ chạy” trong ngày; mỗi tick kiểm tra tới giờ thì sinh bài + đăng. Có giới hạn chống spam (token bucket, khoảng cách tối thiểu giữa các lần gửi) và cap số bài/nhóm/ngày.

Service: AgentManager + Schedule Resolver
Logic CRUD agent; resolver tính giờ chạy từ luật định kỳ + calendar; thay scheduler hiện tại. Verify: unit test resolver (daily/weekly/monthly/once).
3
Generator + Poster gắn theo agent
Sinh bài dùng trợ lý của agent; đăng tới đúng nhóm của agent, kèm ảnh. Verify: Đăng thử ngay theo agent ra đúng nội dung + ảnh.
4
UI: Tab Agents + trình tạo/sửa Agent
Màn hình trung tâm: chọn trợ lý, chủ đề, nhóm, lịch, ảnh, chế độ duyệt. Verify: tạo agent mới → chạy được.
5
UI: Calendar + Bài đăng theo agent
Lịch tháng/tuần/ngày; hàng đợi bài lọc theo agent/trạng thái. Verify: thấy bài dự kiến trên lịch; duyệt/đăng từ đây.
6
UI: Trợ lý AI/API + Thống kê
Quản lý/sửa nhanh trợ lý & API trong tab; dashboard thống kê theo agent/nhóm. Verify: số liệu khớp post_log.
7
Hoàn thiện + build + cài
Dọn UI cũ, log, tài liệu; build 26.7.0 và cài đè. Verify: chạy end-to-end 1 agent đăng tự động qua 1 chu kỳ.

❓ Điểm cần bạn xác nhận trước khi làm

  • Tự đăng vs duyệt tay: mặc định agent nên tự đăng luôn hay chờ bạn duyệt rồi mới đăng? (mỗi agent vẫn chỉnh được)
  • Số bài/nhóm/ngày tối đa để an toàn (tránh khóa Zalo): đề xuất mặc định 1–3, trần 12. OK không?
  • 1 agent nhiều nhóm: cùng 1 bài đăng cho mọi nhóm của agent, hay mỗi nhóm 1 bài khác nhau? (đề xuất: cùng bài, đỡ tốn AI)
  • Giữ tab cũ (Chuyên đề/Duyệt bài/Lịch/Ảnh) song song trong lúc chuyển, hay thay hẳn bằng cấu trúc Agent?
  • Có cần nhiều tài khoản Zalo trong 1 agent, hay 1 agent = 1 tài khoản? (đề xuất: 1 agent = 1 tài khoản)
